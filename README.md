# Makwana-Studio

Official Game Studio & Franchise Destination for **Stones to Stars**.

> *"Before civilization, there was survival."*

## Overview
Stones to Stars is a stylized prehistoric third-person survival adventure game developed by **Makwana**.

## Multi-Page Architecture
- **Home** (`index.html`) — Cinematic emotional gateway & custom reveal trailer cinema player.
- **The Game** (`game.html`) — Survival architecture & core loop (*Explore → Discover → Survive → Adapt → Progress*).
- **Season 01: Stone Age** (`season-01.html`) — The First Valley vertical slice & Cinder predator encounter.
- **World & Biomes** (`world.html`) — Archaia map, 4 interactive biomes & 4-season dynamic weather scrubber.
- **People** (`people.html`) — Early human protagonist Hu & interactive movement stances.
- **Wildlife** (`wildlife.html`) — Primeval ecosystem, predator perception & sensory AI profiles.
- **Equipment** (`equipment.html`) — Authentic Stone Age flintcraft bench & primitive material tiers.
- **Field Notes / News** (`news.html`) — Development logs & updates.
- **Community** (`community.html`) — Community showcase & portals (Discord, Reddit, GitHub, X).
- **Contribute** (`contribute.html`) — Open development, issues, and portfolio-building guidance.
- **Join Us** (`join-us.html`) — Authentic indie careers portal with Expression of Interest form.
- **Media & Press Kit** (`media.html`) — Official studio factsheet, 4K screenshots, and transparent logo assets.
- **About Makwana** (`about.html`) — Studio origin story & creative philosophy.
- **Play** (`play.html`) — PC development status, system requirements, and Alpha test registration.

## Tech Stack
- **Engine / Ambient**: Three.js atmospheric canvas & particle systems
- **Animation & Motion**: GSAP & ScrollTrigger
- **Smooth Inertia**: Lenis
- **Build Tool**: Vite

## Local Development
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
